Shared rules for every variant of the group "Inbox and lists". A builder must read them with the variant spec.

SURFACES. Seven surfaces: run-row, status-mark, queue-summary, history-filter, empty-state, attempt-timeline, alert-card. Changes to the starting list: history rows are the scenario `past` of run-row, so one row serves the Queue and History; the history filter bar is its own surface; loading and refresh are scenarios of each surface, not a surface.

1. WORDS (ui-copy terminology, one name per concept). Pages: Queue, History, Status. Things: run, screenshot, variant, change (a variant that still needs a verdict), baseline, current, alert, commit, attempt. Run states: Needs review, Rejected, Failed, Rerun needed, Comparing, Capturing, Passed, Replaced. Variant states: Needs review, Approved, Auto-approved, Rejected, Unchanged, Comparing, Failed. Queue sections: To review, In progress, Needs attention. Do not use `runStateLabels[state].short` for `needs-review` (it says Review) and `needs-recompare` (it says Stale): define a local word map. Sentence case. No period at the end of a heading or a label. Never print: view, awaiting approval, capture run, Checking access, Pull request as a title.

2. STATUS MAP (word, lucide icon, color role). Runs: needs-review = Needs review, `CircleDot`, warning. rejected = Rejected, `CircleX`, danger. failed = Failed, `TriangleAlert`, danger. needs-recompare = Rerun needed, `RefreshCw`, warning. comparing = Comparing, `LoaderCircle` (turns), neutral. incomplete = Capturing, `CircleDashed`, neutral. passed = Passed, `CircleCheck`, success. superseded = Replaced, `CircleArrowRight`, neutral. Variants: Needs review, Rejected, Comparing, and Failed as for runs; Approved, `CircleCheck`, success; Auto-approved, `CheckCheck`, neutral; Unchanged, `Minus`, neutral. For a layer prop map neutral to `true`. Color never stands alone: each state has its own shape or its word.

3. COUNTS AND STATE TEXT. changes = `run.pending - run.rejected` (the API count `pending` includes the rejected variants; this removes the ambiguity of audit finding DASH-25). Use `formatCount(n, 'change')`. State text of a run: `79 changes`; `22 changes · 2 rejected`; `Capturing 212 of 600`; `Comparing 6 of 16`; `Failed`; `Rerun needed`; `Passed`; `Replaced`. Numbers use `tabular-nums`.

4. RUN IDENTITY. Pull request run: `#4831` and the title. No title (production today, DASH-05): `#4831` takes the title place. Main run: the first line of the commit message if present, else `main` and the 7-character commit. Merge queue run: `Merge queue` and the pull request numbers if present, else the commit. `attempt 3` in soft text, only from attempt 2. Time: `formatRelativeTime` inside `Text render={<time dateTime={new Date(value).toISOString()} title={formatDateTime(value)} />}`; dense rows drop the word `ago`.

5. LINKS AND KEYS. The whole row is one link and one tab stop: `LabLink to='review' scenario='changes'` (use `large` for #4831, `one-change` for #4835, `comparing` for #4855, `problems` for #4844). Keys are key map B of the gap-contract-map lane, which has no conflicts: J or Down = next row, K or Up = previous row, Enter = open, `/` = focus the filter field, `?` = key list. Bind keys with one `onKeyDown` on the root element of the variant, never on the document: the explorer shows many variants in one document. Do not bind R, G, brackets, Space, or Cmd/Ctrl+K. Show keys with `Kbd`.

6. WAITS. Loading is a skeleton with the final geometry: `Frame $lightnessOffset` blocks with `animate-pulse motion-reduce:animate-none`, and the root has `aria-busy='true'` and an `aria-label` such as `Loading runs`. No loading sentence. A refresh keeps the content on screen; the refresh button uses `aria-busy`, not `disabled`, so it keeps the focus.

7. THEME AND WIDTH. Colors come only from `$layer`, `$text`, `$mix`, `$edge` with the roles canvas, brand, success, warning, danger, and from `ak-ink-*`. No hex values, no palette classes, no `$layer='primary'`, no `ak-ink-danger`. Spacing steps and named radius steps only. Dark is first; check `?theme=light` and give each raised surface a `$border`. A stack cell is a size container: use container variants (`@md:`, `@max-md:`), not viewport breakpoints. At 390 px there is no horizontal page scroll and a target is at least 2.75em high. A row-layout variant sets its own width: `w-90 max-w-full`.

8. PRIMITIVE PITFALLS. `$forceRounded` on a `Badge` or `Button` in a table cell or in a frame with less than 1rem of padding. `Text` has no `$ink`: use `ak-ink-60` or `ak-ink-70`. `$text` colors only label and slot parts of a control. `Heading` needs `mt-0 mb-0`. Popovers and tooltips need `portal`. `List` is for content; rows that act are `Nav`, `Button`, or `Table`.

9. DATA. Fixtures only (`getInboxData`, `getHistoryData`, `getPullData`, `getStatusData`, and the hooks). Find a run by its pull request number, not by index. No `Date.now()`, no `new Date()` without an argument, no `toLocaleString()`. Not in the API today, so name them in the lab: run `author`, `branch`, `commitMessage`, `counts`, `progress`, `durationMs`, `reviewers`, `error`, `mergeGroupPullRequests`, `previews`; alert `severity`, `impact`, `occurrences`, `runId`; the pull request `title`, `author`, `branch`, `headSha`, and `runs`.

10. EARLIER DECISIONS THAT THIS GROUP TOUCHES. (a) The eight state words and `Auto-approved` replace contract strings such as `Accepted automatically` (RULE-26). (b) Marks without a visible word (compact forms) go against rule A09, text with color. (c) A table or tabs with an All view for the Queue are close to the option `recent-clear` that U05 rejected; the Queue order stays work first. (d) The contract has no key for the dashboard, and the maintainer said no hotkey registry: the keys here are local handlers. `/` is quick find in Firefox; D53 names Chrome Desktop. (e) A pull request view with all runs reopens the note that a title feature does not need another dashboard (group G21 of the contract map). (f) The alert list is read-only: no variant adds acknowledge or dismiss. The review guide asks for a recovery action, the subject, and first-seen and last-seen times for each alert; a variant that puts them behind a disclosure says so. (g) Polling of the run list is not in the app (DASH-19 needs a decision on its cost).
