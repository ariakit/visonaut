  <h4 id="your-answers-plan-read">How to read the plan</h4>

  <ul class="wide">
    <li>
      <strong>A level</strong> is a set of issues that can be in work at the same time. Level 0
      depends on no other issue. An issue of level 2 needs something from level 0 or level 1.
    </li>
    <li>
      <strong>“Depends on”</strong> names pull requests, and not a complete issue. Example:
      <code>ops</code> depends on <code>live-defects</code>, and that means only that step 1 of
      <code>live-defects</code> is merged. So a late step of an issue that waits for you does not
      hold the issues after it.
    </li>
    <li>
      <strong>“A part waits”</strong> means that one pull request of the issue waits, and each
      other pull request of that issue can start.
    </li>
    <li>
      <strong>The size</strong> is an estimate of the work of one session: M is two to four pull
      requests, and L is five or more, or fewer that are large.
    </li>
  </ul>
