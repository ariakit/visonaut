<h4 id="state-checks-pass-log">What the log of a failed pass can say</h4>

<p>
  This is the open part of row 7 of the list above. The service runs a background pass each 5
  minutes and after each event: it sends check results to GitHub, promotes baselines, and deletes
  old images. A pass writes to the log of the Cloudflare Worker.
  <span data-fact="assumption"
    >Only a person with access to the Cloudflare account of the service can read that log. The audit
    did not read the account settings.</span
  >
  It is not the CI log of a repository, and it is not public.
  <span data-findings="OPS-08 OPS-11"></span>
</p>

<p>A pass can fail in two ways, and today the code drops the error in both.</p>

      </td>
      <td>Nowhere</td>
    </tr>
  </tbody>
</table>

<p>
  The rule that this choice is near:
  <a
    href="https://github.com/ariakit/visonaut/blob/f83fef6bfcaeb44ad0ed8fa91d5ae6cd4a1ecc90/docs/current-contract.md#L81"
    >contract, line 81</a
  >
  says of the failure line <code>operation-failed</code> that it has <q>fixed operation, code,
  correlation ID, and elapsed-time fields</q>, and: <q>No request body, token, URL, SQL, raw
  exception, or private label is added to that log.</q> The line <code>operations_pass</code> of a
  pass is another line, and the contract has no sentence about it. The code has one rule for all
  Worker logs:
  <q>Fixed fields keep credentials, request payloads, and SQL out of Worker logs</q>
  (<code>apps/web/src/operations/failure.ts</code>, line 13).
  <span data-fact="counted"
    >6 error classes of the server set a fixed name, and the GitHub error keeps the status number
    (<code>github.ts</code>, line 24).</span
  >
  The second auditor read line 81 in this way: a class name and a status number are not a raw
  exception.
  <span data-fact="counted"
    >One place of the code already logs a fixed value of an error: a failed recovery of GitHub
    deliveries writes the code of its error to the failure line when the code is on a list of 13
    (<code>apps/web/src/runtime.ts</code>, lines 334 to 358).</span
  >
</p>
