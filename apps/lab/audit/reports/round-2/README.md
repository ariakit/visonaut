# Research record of feedback round 1

This folder holds the work behind revision r2 of the audit document: the feedback of the maintainer (`feedback.md`), and one folder for each research lane with its notes, its result, the result of its independent check, and its measurement scripts with the recorded output.

A script has the suffix `.txt` after its real extension, for example `pack.ts.txt`, so that the lint and the type check of the repository do not read it. Remove the suffix to run it. The scripts ran from a scratch folder, so their paths need a change first.
