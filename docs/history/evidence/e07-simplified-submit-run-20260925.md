# One-Submit Ariakit visual run

[Ariakit CI run 36133866843](https://github.com/ariakit/ariakit/actions/runs/36133866843) exercised the simplified pull-request workflow at commit [`c7f15a0`](https://github.com/ariakit/ariakit/commit/c7f15a02ed709f45180da1909c4192cd96f99197) on September 25, 2026. The existing Linux Chrome/Firefox and macOS Safari visual jobs passed and packed encrypted artifacts. A single OIDC-enabled Submit job downloaded both artifacts and called `visonaut submit` once. [Visonaut run `4cd2d53c`](https://visonaut.com/runs/4cd2d53c-dc14-42e6-91d5-74427752dd9c) sealed with 1,058 review variants, of which 1,057 reused earlier decisions and one required a human approval. The Visonaut App check then passed. Gate first failed while review was pending and passed when rerun after approval. This validates the chosen fail-closed path on a pull request before a main reference baseline; it is not a main-baseline comparison or full cutover.

The [sanitized project-resource meter receipt](./e07-simplified-submit-run-20260925.json) compares read-only Cloudflare GraphQL snapshots. Worker, R2, and Queue analytics use cumulative windows from 12:00 to 12:15 and 12:00 to 12:50 UTC, queried at 12:15:59 and 12:55:39. Production service requests increased by 1,624, comparison invocations by 993, and webhook-router requests by 203. The production image bucket recorded 992 additional `PutObject` and 1,171 `GetObject` operations. The production D1 **calendar-day** counter increased by 1,453,621 rows read and 33,628 rows written between queries. All five GraphQL query groups returned HTTP 200 with no reported errors.

These deltas include other project activity, and the D1 filter spans the day rather than the 35-minute Worker/R2 windows. Provider analytics can sample or lag, so the numbers do not assign every operation to this run or represent billable usage. They show that this real workflow was far smaller than the deleted synthetic capacity workload behind the earlier cost alert. The delayed account bill, monthly run frequency, retained-image churn, backup/export cost, and target-scale throughput remain open under [E07](./e07-cost-admission.md). No new synthetic stress database was created for this measurement.
