# Submit original reuse, local evidence

The focused transport test in `packages/cli/test/declaration.test.ts` runs `visonaut upload --dir` for 67 distinct PNG originals against a local mock service. Without reuse, the image-transfer path makes 71 HTTP requests: OIDC, reserve, declare, 67 image PUTs, and finalize. When the service confirms 66 proofs and one image has no retained source, the same path makes 8 requests: OIDC, reserve, declare, three bounded proof pages, one image PUT, and finalize. This is 63 fewer requests, or 89% fewer requests after rounding. `visonaut submit` uses this image-transfer path, then makes additional transfer-key and submit requests that this fixture does not measure. The proof pages contain at most 32 images and 8 MiB of declared original bytes.

The staged-workflow API tests use Miniflare D1 and R2 bindings. They confirm that the server rehashes a previously validated, live, same-repository original, checks the local-byte proof, copies those bytes to a new run-owned key, and marks the new staged image complete. They also confirm upload fallback for foreign, deleting, deleted, incomplete, missing, and corrupt sources. The tests use local storage only and cause no Cloudflare account usage.

Each reused original still requires one R2 write to retain independent evidence for the new run. It adds one R2 read compared with direct upload, while it avoids one public image PUT and one codec validation. [Cloudflare's Standard R2 prices](https://developers.cloudflare.com/r2/pricing/) list Class B reads at $0.36 per million and Class A writes at $4.50 per million, with monthly included usage and billing-unit rounding. These figures cover R2 operations only. They do not measure D1, Worker CPU, or hosted latency.

The measured Ariakit Submit step has taken 6m28s to 16m42s on recent successful jobs. This local fixture proves the request reduction but does not establish a hosted wall-time improvement. Record a real job duration and reuse count after the updated CLI is published and installed in Ariakit.
