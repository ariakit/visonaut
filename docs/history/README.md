# History

This folder holds dated records, old designs, and raw evidence. The current guides are in the parent folder, and the [current implementation contract](../current-contract.md) is the current guide.

## The one file in force

One file of this folder is in force: [`simplification-audit/contract-issue-1.md`](simplification-audit/contract-issue-1.md), the saved text of issue #1. The current contract says that every saved issue #1 requirement remains binding unless an explicit approved rule of the contract supersedes it. Each other file of this folder is a record and not a current instruction.

The first lines of the saved text say "The issue remains the current implementation contract". That sentence is not true since 2026-10-02, when the current contract became the repository contract. The file is a saved copy and does not change, so the sentence stays.

## Paths in a record

A record keeps the text of its date. A path in a record that starts with `docs/` can name a file that is now below `docs/history/`.
