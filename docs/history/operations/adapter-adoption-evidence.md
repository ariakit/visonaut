# Adapter public-default adoption evidence

This record holds the dated evidence that `docs/current-contract.md` carried in its section on comparison settings until the change of issue #401. The current contract keeps only the rule. The paragraph below is the moved text, and it keeps its wording as of [#408](https://github.com/ariakit/visonaut/pull/408) (2026-10-11).

Adapter `0.4.1` is the compatible public-default release and retains the tested Playwright `1.63.0` bridge when explicit defaults are absent. Ariakit adopted explicit defaults with that version in [PR #7718](https://github.com/ariakit/ariakit/pull/7718); normal PR and main capture/Submit checks passed. The approved breaking adapter `0.5.0` was then published and verified through [PR #223](https://github.com/ariakit/visonaut/pull/223), removing private inheritance from that release. Both releases used the exact peer pin. See the [strict release record](strict-adapter-comparison-defaults.md) and [compatible adoption record](adapter-comparison-defaults.md). The separate `0.5.0` consumer upgrade merged in [PR #7720](https://github.com/ariakit/ariakit/pull/7720) after verified native PR capture, signed Submit, service acceptance, and required checks. Ordinary main acceptance is also verified through native CI, signed Submit, the successful Visonaut check, authenticated service History, and a bounded service point read.
